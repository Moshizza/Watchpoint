# Modbus TCP Connector

Connects to Modbus TCP and RTU-over-TCP gateways and field devices using customizable mapping templates.

## Features
- Standard MBAP framing and RTU-over-TCP framing.
- Configurable register and coil polling with intelligent read coalescing.
- Comprehensive data type encodings (bit, integers, floats, BCD, UTF-8 strings, scale and offset, enum mapping).
- Command mapping for coils and holding registers with pulse sequences and verification read-backs.
