## 1. Purpose and scope

The Kernel holds the small set of types **every** .NET project of Watchpoint uses:
identifiers, results and errors, time helpers, paging, JSON settings, translatable texts and
validation helpers. It has **no dependency** on any other Watchpoint project and only on
these packages: `NodaTime`, `Microsoft.Extensions.TimeProvider.Testing` (testing project
only).

Not in scope: logging setup (HST), persistence (STO), domain types of modules (each module).

## 2. Dependencies

| Uses | Used by |
|---|---|
| .NET BCL, NodaTime | Every service project, every connector project, `Watchpoint.Integration.Abstractions` |

Because connectors reference it through the integration contract, the Kernel's public API is
**versioned** like the contract: only additive changes within a major version.

## 4. Identifiers

### 4.1 UUID-based ids

```csharp
public interface IEntityId<TSelf> : IEquatable<TSelf>, IComparable<TSelf>, ISpanFormattable
    where TSelf : struct, IEntityId<TSelf>
{
    Guid Value { get; }
    static abstract TSelf From(Guid value);          // no validation except != Guid.Empty
    static abstract TSelf New();                      // Guid.CreateVersion7()
    static abstract bool TryParse(string? s, out TSelf id);
    static abstract string Prefix { get; }            // used only in logs and debugging, e.g. "dev"
}

[JsonConverter(typeof(EntityIdJsonConverter<DeviceId>))]
public readonly record struct DeviceId(Guid Value) : IEntityId<DeviceId>
{
    public static string Prefix => "dev";
    public static DeviceId New() => new(Guid.CreateVersion7());
    public static DeviceId From(Guid value) => value == Guid.Empty
        ? throw new ArgumentException("Empty id", nameof(value)) : new(value);
    public override string ToString() => Value.ToString("D");   // lowercase, 36 chars
    // TryParse, CompareTo (by Value bytes — v7 sorts by time), TryFormat
}
```

| `DeviceId` | `dev` | `EventRecordId` | `evt` |
| `LocationId` | `loc` | `CommandId` | `cmd` |
| `TagId` | `tag` | `CalendarId` | `cal` |
| `TagFamilyId` | `tagf` | `SynopticId` | `syn` |
| `LinkId` | `lnk` | `AutomationId` | `auto` |
| `ConnectionId` | `conn` | `AutomationRunId` | `run` |
| `HostId` | `host` | `ScriptId` | `scr` |
| `UserId` | `usr` | `NotificationId` | `ntf` |
| `UserGroupId` | `ugrp` | `ReportId` | `rpt` |
| `SessionId` | `ses` | `FileId` | `file` |
| `RightGrantId` | `grant` | `SecretId` | `sec` |

| `WorkstationId` | `wks` | `IncidentId` | `inc` |

Rules:

- Ids are generated by Watchpoint (never by the database).
- JSON: plain lowercase UUID string. Parsing accepts upper/lower case, rejects other formats
  (braces, no dashes) → `common.value.invalid_format`.
- `ToLogString()` extension returns `"{Prefix}:{Value}"` for logs.
- `Guid.Empty` is never a valid id.

### 4.2 String-based ids

| Type | Pattern | Max length | Example |
|---|---|---|---|
| `TypeId` (device/server type) | `^[a-z][a-z0-9]*(\.[a-z][a-z0-9-]*){1,4}$` | 100 | `ac.door`, `vendor.salto.hotel-room` |
| `CapabilityId` | `^[a-z][a-zA-Z0-9]*(\.[a-z][a-zA-Z0-9]*)?$` | 64 | `doorPosition`, `vendor.saltoDnd` |
| `MemberId` (property/command/event name inside a capability) | `^[a-z][a-zA-Z0-9]*$` | 64 | `position`, `gotoPreset` |
| `PackageId` | `^[a-z][a-z0-9]*(\.[a-z][a-z0-9-]*){1,5}$` | 128 | `watchpoint.integration.salto` |
| `PermissionCode` | `^[a-z][a-zA-Z0-9]*(\.[a-z][a-zA-Z0-9*]*){1,5}$` | 128 | `alarms.acknowledge`, `commands.openable.open` |
| `ErrorCode` | `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*){1,4}$` | 128 | `registry.device.not_found` |

Each is a `readonly record struct` with `Value`, `static Result<T> Parse(string)`,
`static T FromTrusted(string)` (no validation; for constants), ordinal equality,
JSON as string.

`PropertyPath` (used across modules): `"<capabilityId>.<memberId>"`, e.g.
`doorPosition.position`; record struct with `Capability` and `Member`.

### 5.2 `Error`

```csharp
public sealed record Error
{
    public required ErrorCode Code { get; init; }
    public required ErrorKind Kind { get; init; }
    public IReadOnlyDictionary<string, object?> Args { get; init; } = Empty;  // see 5.4
    public IReadOnlyList<FieldError> FieldErrors { get; init; } = [];         // Validation only
    public string MessageKey => "errors." + Code.Value;
    public string? DeveloperDetail { get; init; }   // never sent to clients; logged only

    public static Error Validation(string code, IReadOnlyList<FieldError> fields);
    public static Error NotFound(string code, params (string key, object? value)[] args);
    public static Error Conflict(string code, params (string, object?)[] args);
    public static Error Forbidden(string code, params (string, object?)[] args);
    public static Error Unprocessable(string code, params (string, object?)[] args);
    public static Error Unavailable(string code, params (string, object?)[] args);
    public static Error Internal(string developerDetail);   // code common.internal
    public Error WithArg(string key, object? value);
}

public sealed record FieldError(string Path, ErrorCode Code,
                                IReadOnlyDictionary<string, object?> Args);
// Path = JSON Pointer (RFC 6901) relative to the validated document, e.g. "/settings/port"
```

### 5.3 `Result` and `Result<T>`

```csharp
public readonly struct Result
{
    public bool IsSuccess { get; }
    public Error Error { get; }                 // throws InvalidOperationException if success
    public static Result Success();
    public static Result Failure(Error error);
    public static implicit operator Result(Error error);
}

public readonly struct Result<T>
{
    public bool IsSuccess { get; }
    public T Value { get; }                     // throws InvalidOperationException if failure
    public Error Error { get; }                 // throws InvalidOperationException if success
    public static implicit operator Result<T>(T value);
    public static implicit operator Result<T>(Error error);
    public bool TryGetValue([MaybeNullWhen(false)] out T value, [MaybeNullWhen(true)] out Error error);
}
```

Extensions (`ResultExtensions`): `Map`, `Bind`, `Ensure(predicate, error)`, `Match`,
`Tap`, `MapError`, async versions on `Task<Result<T>>` / `ValueTask<Result<T>>`, and
`Combine(params Result[])` which merges validation errors (field errors concatenated;
otherwise the first error wins).

Rules:

- `default(Result<T>)` is invalid; accessing it throws (`IsSuccess` false and `Error` throws
  "uninitialised result") — the analyzer rule `WP0001` (in TST) flags `default` results.
- Business failures are never thrown as exceptions across module boundaries.

### 5.4 Error and message arguments

Allowed argument value types (checked by `Error`/`Message` constructors in DEBUG builds and
by unit tests of each module): `string`, `int`, `long`, `double`, `decimal`, `bool`,
`DateTimeOffset`, `Guid`, any `IEntityId`, string-based ids, `IReadOnlyList<string>`.
Anything else → `ArgumentException` (programming error). Names of arguments are camelCase.

## 6. Time

- All modules depend on **`TimeProvider`** (registered as `TimeProvider.System`; tests use
  `FakeTimeProvider`). "IClock" in the README means this.
- `TimeProviderExtensions.UtcNowMs(this TimeProvider)` returns `DateTimeOffset` truncated to
  milliseconds with offset zero (storage precision everywhere is milliseconds).
- `SiteTimeZone` (NodaTime):

```csharp
public sealed class SiteTimeZone
{
    public static Result<SiteTimeZone> FromIana(string tzId);   // "Europe/Paris"; invalid → common.value.invalid_format
    public string Id { get; }
    public LocalDateTime ToLocal(DateTimeOffset utc);
    public DateTimeOffset ToUtc(LocalDateTime local, AmbiguityPolicy policy); // gaps/overlaps per policy
}
public enum AmbiguityPolicy { EarlierOffset, LaterOffset, Reject }
```

- JSON: `DateTimeOffset` written as `yyyy-MM-ddTHH:mm:ss.fffZ` (always UTC, `Z`); reading
  accepts any ISO 8601 with offset and converts to UTC; values without offset are rejected
  (`common.value.invalid_format`).
- `TimeSpan` in configuration documents and API: ISO 8601 duration (`PT10S`, `PT1H30M`,
  `P1D`); months and years are rejected (ambiguous). Converter: `Iso8601DurationConverter`.

## 7. Paging, sorting, cursors

```csharp
public sealed record PageRequest(int Limit = 100, string? Cursor = null)
{
    public const int MaxLimit = 1000;
    public static Result<PageRequest> Create(int? limit, string? cursor); // limit 1..1000
}
public sealed record Page<T>(IReadOnlyList<T> Items, string? NextCursor);

public sealed record SortSpec(IReadOnlyList<SortField> Fields)
{
    // "name,-createdAt" → [name asc, createdAt desc]; validated against allowed fields
    public static Result<SortSpec> Parse(string? text, IReadOnlySet<string> allowed, SortSpec @default);
}
public sealed record SortField(string Name, bool Descending);

public static class CursorCodec
{
    // Cursor = base64url(UTF-8 JSON {"v":1,"k":[...last sort key values...],"id":"<uuid>"})
    public static string Encode(int version, IReadOnlyList<object?> keyValues, Guid lastId);
    public static Result<DecodedCursor> Decode(string cursor, int expectedVersion);
}
public sealed record DecodedCursor(IReadOnlyList<JsonElement> KeyValues, Guid LastId);
```

Keyset paging only (no offsets). The `id` tie-breaker makes paging stable. Cursors are
opaque to clients; a cursor from another query or version → `common.cursor.invalid`.

## 8. Texts

### 8.1 `Message` (translatable system text)

```csharp
public sealed record Message(string Key, IReadOnlyDictionary<string, object?> Args)
{
    public static Message Of(string key, params (string name, object? value)[] args);
}
```

Used for events, notices and anything shown to users that is produced by the system. Keys
are lowercase dotted (`events.door.forced.title`). Argument rules as §5.4.

### 8.2 `LocalizedName` (user content)

```csharp
public sealed record LocalizedName(string Default, IReadOnlyDictionary<string, string> Translations)
{
    public string Resolve(string culture);  // exact culture → neutral ("fr-CA" → "fr") → Default
}
```

JSON: `{ "default": "Main entrance", "translations": { "fr": "Entrée principale", "ar": "المدخل الرئيسي" } }`.
Translations keys must be in `SupportedCultures.All` (validation error otherwise).

### 8.3 `SupportedCultures`

`All = ["en", "fr", "ar"]` (v1); `RightToLeft = ["ar"]`; `Default = "en"`. Adding a culture is
a code change in one place.

### 8.4 `NameRules`

Display names (devices, servers, locations, users' display names, rules…):

- trimmed; length 1–200; no control characters (Unicode category Cc); no
  leading/trailing whitespace; Unicode normalised to NFC.
- Comparison for uniqueness (where a module requires it): `string.Compare(a, b,
  CultureInfo.InvariantCulture, CompareOptions.IgnoreCase | CompareOptions.IgnoreNonSpace)`
  after NFC.
- `NameRules.Validate(string? value, string path)` → `IReadOnlyList<FieldError>`.

## 9. JSON and validation helpers

### 9.1 `WatchpointJson`

```csharp
public static class WatchpointJson
{
    // camelCase, enums as camelCase strings, UTC date converter, ISO duration converter,
    // id converters, MaxDepth 64, NumberHandling Strict, no NaN/Infinity,
    // UnmappedMemberHandling per profile.
    public static JsonSerializerOptions Create(JsonProfile profile, params IJsonTypeInfoResolver[] resolvers);
}
public enum JsonProfile
{
    Api,            // unknown members ignored on input (forward compatibility of clients)
    Document,       // configuration documents: unknown members rejected
    Log             // event log records: unknown members ignored (newer writers), never throws on extra fields
}
```

Every module declares its own `JsonSerializerContext` (source generation) and passes it to
`Create`. Reflection-based serialisation is disabled in the host
(`JsonSerializerIsReflectionEnabledByDefault=false`).

### 9.2 `ValidationBuilder`

```csharp
var v = new ValidationBuilder();
v.Required("/name", dto.Name)
 .Name("/name", dto.Name)                 // NameRules
 .Range("/settings/port", dto.Port, 1, 65535)
 .MaxLength("/description", dto.Description, 2000)
 .Pattern("/code", dto.Code, Regex, expected: "lowercase letters")
 .Custom("/items", () => CheckItems(dto.Items));   // returns IEnumerable<FieldError>
Result result = v.Build();   // Success, or Error common.validation.failed with all field errors
```

Collects **all** problems (does not stop at the first). Paths are JSON Pointers; helpers
escape `~` and `/` in segment names.

### 9.3 `Guard`

`Guard.NotNull`, `NotEmpty`, `InRange` — throw `ArgumentException` family; only for
programming errors (parameters from code, not from users).

## 10. Values (`WpValue`)

The single representation of a property value, command argument or event payload field,
used by MOD, PIP, STA, CMD, ALM, EXP and by connectors (through the integration contract).

```csharp
public enum WpValueKind { Null, Bool, Int, Decimal, Enum, String, Timestamp, Duration, Geo, List, Object }

public readonly struct WpValue : IEquatable<WpValue>
{
    public WpValueKind Kind { get; }
    public static readonly WpValue Null;
    public static WpValue Bool(bool v);
    public static WpValue Int(long v);
    public static WpValue Decimal(decimal v);
    public static WpValue Enum(string code);                // code pattern ^[a-z][a-zA-Z0-9]*$
    public static WpValue String(string v);
    public static WpValue Timestamp(DateTimeOffset utc);    // converted to UTC, ms precision
    public static WpValue Duration(TimeSpan v);
    public static WpValue Geo(double lat, double lon, double? alt = null);
    public static WpValue List(IReadOnlyList<WpValue> items);
    public static WpValue Object(JsonElement value);        // cloned, immutable

    public bool AsBool(); public long AsInt(); public decimal AsDecimal(); public string AsEnum();
    public string AsString(); public DateTimeOffset AsTimestamp(); public TimeSpan AsDuration();
    public GeoPoint AsGeo(); public IReadOnlyList<WpValue> AsList(); public JsonElement AsObject();
    // As*() throw InvalidOperationException on kind mismatch; TryAs*() variants return bool.
}
public readonly record struct GeoPoint(double Latitude, double Longitude, double? Altitude);

// Shared by MOD, PIP, STA and the integration contract (which may only depend on the Kernel):
public enum Quality { Good, Uncertain, Bad, Stale }
public enum Connectivity { Online, Degraded, Offline, Unknown }
```

- Equality: same kind and equal value (`Decimal` compared numerically: `1.0 == 1.00`;
  `Object` compared by canonical JSON; `List` element-wise).
- JSON form (`WpValueJsonConverter`), used in the event log, API and documents:
  `{"k":"bool","v":true}`, `{"k":"int","v":5}`, `{"k":"dec","v":"21.5"}` (decimal as string to
  keep precision), `{"k":"enum","v":"open"}`, `{"k":"str","v":"text"}`,
  `{"k":"ts","v":"2026-11-03T09:00:00.000Z"}`, `{"k":"dur","v":"PT10S"}`,
  `{"k":"geo","v":[48.85,2.35]}`, `{"k":"list","v":[…]}`, `{"k":"obj","v":{…}}`, `{"k":"null"}`.
  A **compact form** without kind (plain JSON value) is accepted where the target type is known
  (API inputs validated against a property definition); MOD converts it.
- Size limits: strings 16 KB, lists 1,000 items, objects 16 KB serialised, depth 8.

- `DeveloperDetail` of errors is never serialised by API (enforced by API tests).
