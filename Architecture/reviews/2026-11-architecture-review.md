## Top 10

1. (1.1, H) `tasks.md` lists **T1.09b twice and T1.10 twice** with contradicting rows (one `done`, one `todo`, different test ranges); `next-task.py` and readers see a `todo` T1.10 that is merged.

3. (2.3, H) REG §9 error catalogue (20 codes) vs code: the writer emits only `registry.entity_not_found`, `common.version.conflict` and a generic invariant error; API and UI tasks map plain-language messages from these codes.
4. (1.6, M) Hand-offs of T1.10/T1.09b are tracked nowhere: last-value purge for deleted devices, dev-seed site/locations/tags steps, outbox record size check before commit, `IIngestFloodingListener` implementer, HST-I-008 enablement text stale.

7. (2.8, M) HST §14 note and §9 say the Registry module is not yet in the host catalogue; it is (T1.09). The remaining gap is only the REG seed steps.
8. (2.10, M) IDN §7.2 lists both `POST /api/v1/auth/mfa/enrol/totp` and `POST /api/v1/auth/mfa/totp/enroll`; IDN §14 event table misses 2700, 2791, 2792, 2799 used by the code.
9. (1.3, L→M) Stale § references in `tasks.md` (T1.02 omits HST §9, T1.07 omits REG §9–§13, T1.10 row cites PIP §13).
10. (2.1, L) PIP §3, REG §3, IRT §3 project layouts no longer match the file lists (missing files, moved files, module classes in wrongly named host files).
